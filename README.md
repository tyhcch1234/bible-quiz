# 聖經問答練習

按聖經書卷次序編排的繁體中文問答練習。**66 卷書、817 題**，每卷 10 至 20 題，全部答案以和合本經文為根據，並附經文出處與簡短解釋。

## 特點

- **逐卷練習**：由創世記到啟示錄，66 卷齊備，每卷題目不少於 10 題。
- **答案分佈均衡**：正確答案平均分佈於 A/B/C/D（各約 204 題），每卷內四項也大致相近，無法靠「一路選 A」取分。
- **經文根據**：每題附 `書卷 章:節` 出處及解釋，答案直接出自聖經記述，不摻入傳統或推測。
- **即時回饋**：選答後即時顯示對錯、正確答案、經文與解釋。
- **進度記錄**：以瀏覽器 localStorage 記錄每卷完成度、正確率、連對次數與錯題。
- **錯題重練**：可針對全書卷或單節練習的錯題重做。
- **多種模式**：逐卷順序、單卷隨機十題、全書卷隨機二十題。
- **鍵盤操作**：`1`–`4` 選答，`Enter` 下一題。
- **深淺色主題**、手機／平板 responsive、可離線使用（純靜態，無外部依賴）。

## 使用

直接開啟 `index.html` 即可，或部署到任何靜態網站空間（GitHub Pages、Netlify 等）。

本地預覽：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 檔案結構

```
index.html          頁面結構
assets/app.css      樣式（含深色模式）
assets/app.js       練習流程、計分、進度儲存
data.js             題庫（由 data/ 合併產生）
data/SPEC.md        題目撰寫規格
data/b01.json ...   逐卷題庫（原始資料）
build_data.py       合併／驗證題庫，產生 data.js
```

修改題目後重新產生題庫：

```bash
python3 build_data.py
```

驗證會檢查：66 卷齊全、每卷 10–30 題、每題四個選項且答案索引正確、選項不重複、題目文字不重複。驗證不通過時不會覆寫 `data.js`。
